## Inter font (SIL OFL 1.1)

The self-hosted variable font is from
[the official Inter repository](https://github.com/rsms/inter). Preserve
`public/fonts/OFL.txt` alongside the font. Copyright: The Inter Project Authors.

The default preload uses `public/fonts/inter-latin-core.woff2` (41,408 bytes).
This subset covers ASCII, characters used by the Spanish dictionary, common
dashes and quotation marks, copyright, degree, middle dot, bullet, ellipsis,
euro, trademark and minus symbols. The exact ranges are declared in
`src/app/globals.css` and reproduced by `scripts/subset-inter.py`. Ordinary
`@font-face` rules and explicit font preloads in the two router shells use the
same local URL. The existing Latin/extended Latin subset,
`inter-variable-latin.woff2` (146,084 bytes), loads on demand for the remaining
glyph coverage. The original `inter-variable.woff2` (352,240 bytes) remains
included for broader Inter coverage. All retain the OFL license and the original
`opsz` and `wght` variable axes. The core keeps the default contextual,
localization, and kerning features; unused fraction/numerator/denominator
features remain available in the original fonts. Inter does not supply Japanese
glyphs; those use the platform fallback font.

`scripts/subset-inter.py` reproduces the core subset from the retained Latin
subset. FontTools 4.66.1 and Brotli 1.2.1 are optional font-maintenance tools,
not application runtime dependencies. Preserve the source fonts and
`public/fonts/OFL.txt` when regenerating the subset.
