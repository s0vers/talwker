# Historical marketplace records

Talkwer began as a commercial template submission and received an Envato hard rejection. These files preserve that preparation work and the provenance of bundled images. They do not describe the current open-source release requirements.

- `assets.json` records demo-image generation details and checksums. The author authorized MIT distribution on October 27, 2026.
- `artwork-assets.json` records the composed gallery images under `public/envato/`; these are also included under MIT.
- `READINESS.md`, listing copy, submission evidence, and artwork notes are dated historical records.
- `preview-links.json` is the most recent local English anchor-crawl report.

The optional `pnpm package:theme` command preserves the old dimension-placeholder ZIP workflow. The optional `pnpm check:marketplace` command still checks commercial submission evidence and may fail; neither command is required to use or contribute to the open-source project.

Current setup and release guidance lives in the root README, CONTRIBUTING.md, and `docs/RELEASE_CHECKLIST.md`.
